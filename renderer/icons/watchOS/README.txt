Copy AppIcon.appiconset into the watch app target asset catalog and select AppIcon in its build settings. Xcode derives watchOS variants from the unmasked opaque 1024px source. AdditionalSizes contains reference PNGs, not asset catalog slots. Inspect the compiled and installed icon for your deployment target. For modern layered appearances, use the separate 1088px artwork tool, import its layers into Icon Composer and add the saved .icon file to Xcode.
